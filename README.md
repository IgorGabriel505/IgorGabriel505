# 📌 Projetos em Destaque

## 🤖 UV-Care Robot

Aplicativo Android desenvolvido em **Java** para controle e monitoramento de um robô destinado à utilização de luz UV.

O projeto envolve autenticação de usuários, interface de controle, gerenciamento de missões e monitoramento do estado do robô.

### Tecnologias

`Java` · `Android Studio` · `Firebase`

---

## 💧 Caixa d'Água Inteligente

Projeto de sistema inteligente para **captação, tratamento e reutilização de água da chuva**, integrando componentes eletrônicos com software.

O sistema utiliza **ESP32**, sensores, bombas e válvulas para realizar monitoramento e controle dos processos.

### Tecnologias

`ESP32` · `Arduino` · `C/C++` · `Sensores` · `Automação`
